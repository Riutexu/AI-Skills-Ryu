# Checklist básico: React y Next.js

- [ ] Proyecto creado (Vite con plantilla React) y `npm run dev` funciona
- [ ] `App` renderiza componentes propios y elimina el demo de Vite
- [ ] Componentes en PascalCase, un componente por archivo
- [ ] Props desestructuradas; padre pasa datos al hijo
- [ ] Estado con `useState`; nunca se muta directamente (spread / filter / map)
- [ ] Eventos con `onClick`/`onSubmit` y `e.preventDefault()` en formularios
- [ ] Formularios controlados (`value` + `onChange`)
- [ ] Listas con `.map()` y `key` única y estable
- [ ] Renderizado condicional (vacio/loading) con `&&` o ternaria
- [ ] Interfaz probada en navegador: estado inicial, añadir, borrar
