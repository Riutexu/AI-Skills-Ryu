# Checklist profesional: SEO técnico

- [ ] Lighthouse CI en cada PR con presupuestos por página clave
- [ ] CrUX/RUM monitorizado; alertas al superar P75 de LCP/CLS/INP
- [ ] hreflang simétrico, validado y sin contradicciones con canonical
- [ ] Sitemap index con subsitemaps y prioridades por sección
- [ ] Facetas/duplicados resueltos (canonical o noindex)
- [ ] SPA indexable: SSR/SSG/prerender verificado con URL Inspection
- [ ] Sin páginas huérfanas; crawl completo periódico
- [ ] Migraciones con 301 1:1 y seguimiento de 30-60 días
- [ ] Informe mensual de cobertura, CWV y posiciones
