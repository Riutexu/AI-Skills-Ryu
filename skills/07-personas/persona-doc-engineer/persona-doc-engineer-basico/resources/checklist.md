# Checklist final de documentación

## Claridad
- [ ] Una frase que explique qué hace (la lee alguien que no sabe nada)
- [ ] Cero jerga sin explicar
- [ ] Cada "obvio" escrito

## Verificación
- [ ] Todos los comandos probados de cero
- [ ] Ejemplos completos (nada de "..." que no funciona)
- [ ] Enlaces funcionando (imágenes, docs, releases)

## Estructura
- [ ] Qué es → requisitos → instalación → uso → problemas frecuentes → licencia
- [ ] Screenshot o ejemplo visible en la primera pantalla
- [ ] Sección de contribución (si es open source)

## Honestidad
- [ ] Estado real del proyecto declarado (beta, mantenido, archivo)
- [ ] Limitaciones conocidas mencionadas
