# Checklist básico: SEO técnico

- [ ] Title único por página, < 60 caracteres, con la keyword
- [ ] Meta description única (140-160 caracteres) con llamada a la acción
- [ ] Un solo `h1`; headings jerárquicos sin saltos
- [ ] `alt` descriptivo en imágenes (vacío si decorativas)
- [ ] URLs limpias (minúsculas, guiones, sin params)
- [ ] Landmarks semánticos y enlaces con texto de ancla descriptivo
- [ ] `lang`, charset y viewport correctos
- [ ] HTML validado sin errores estructurales
- [ ] Página accesible vía enlaces internos (no huérfanos)
