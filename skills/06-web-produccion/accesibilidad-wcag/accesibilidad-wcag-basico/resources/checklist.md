# Checklist básico: Accesibilidad WCAG

- [ ] Contraste AA (4.5:1 texto, 3:1 grande) en toda la UI
- [ ] Alt descriptivo en imágenes; `alt=""` en decorativas
- [ ] Landmarks semánticos y un solo `<main>`
- [ ] `lang` correcto en `<html>`
- [ ] Todos los inputs con `<label>` asociado
- [ ] Errores de formulario visibles y con aria-describedby
- [ ] Navegación completa por teclado con foco visible
- [ ] Sin tabindex > 0 innecesario
- [ ] Zoom 200% sin pérdida de contenido o solapamiento
