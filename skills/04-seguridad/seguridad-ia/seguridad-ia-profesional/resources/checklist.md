# Checklist — Seguridad de IA nivel profesional

## Govern
- [ ] Inventario de modelos con dueño y uso
- [ ] Política de IA y criterios de alto riesgo aprobados
- [ ] Roles asignados (modelo / riesgo / respuesta)

## Map
- [ ] Registro de riesgos por modelo (contexto, actores, impactos)
- [ ] Dependencias de la cadena documentadas (proveedor, RAG, fine-tuning)
- [ ] Re-mapeo tras cambios

## Measure
- [ ] Métricas automatizadas (bypass taux, PII out, coste anómalo)
- [ ] Baselines mensuales por modelo
- [ ] Panel con tendencias

## Manage
- [ ] Decisiones documentadas (mitigar/transferir/evitar/aceptar)
- [ ] Revisión trimestral del registro
- [ ] Red teaming programado con entorno aislado

## Profundización
- [ ] Batería multicapa ejecutada (injection directa/indirecta, codificación, RAG, coste)
- [ ] Adversarial ML evaluado (relevante vs no) y documentado
- [ ] Bypasses → fix + test de regresión

## Operación
- [ ] Playbook de incidentes de IA existente
- [ ] Ejercicio de mesa realizado
- [ ] Logging con redacción y retención definida
- [ ] Seguimiento de remediación con fecha y dueño
