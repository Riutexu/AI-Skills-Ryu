# Checklist avanzado: SEO técnico

- [ ] JSON-LD por tipo de página y validado (Rich Results Test)
- [ ] Open Graph + Twitter Cards con og:image válida
- [ ] Canonical correcto en 100% de páginas
- [ ] sitemap.xml válido y referenciado en robots.txt
- [ ] robots.txt sensato, sin bloquear CSS/JS
- [ ] hreflang inicial configurado si multi-idioma
- [ ] 301/404 correctos, sin cadenas ni páginas vacías
- [ ] CWV dentro de umbrales (LCP < 2.5s, CLS < 0.1, INP < 200ms)
- [ ] Search Console: cobertura limpia en páginas clave
