# Checklist — Seguridad ofensiva nivel profesional

## Planificación
- [ ] Alcance firmado con objetivos de seguridad explícitos
- [ ] Reglas de impacto y canal de emergencia definidos
- [ ] Equipo de contacto del cliente confirmado

## Ejecución
- [ ] Fases ejecutadas según plan (externo → interno → objetivo)
- [ ] Timeline registrado con hora y evidencia por acción
- [ ] Detecciones documentadas (si es objetivo del engagement)
- [ ] Persistencia solo demostrativa y revertida
- [ ] Cero interrupción de servicios críticos

## Entrega
- [ ] Reporte ejecutivo (riesgos de negocio + prioridades)
- [ ] Reporte técnico (hallazgos, ATT&CK, CVSS, timeline, IoCs)
- [ ] Sesión de presentación y plan de remediación
- [ ] Datos capturados destruidos al terminar
- [ ] Cierre y seguimiento de remediación agendado
