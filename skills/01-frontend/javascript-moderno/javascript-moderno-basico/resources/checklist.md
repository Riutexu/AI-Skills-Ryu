# Checklist — JavaScript Moderno Básico

Marca cada punto cuando lo domines. Úsalo como guía de autoevaluación tras cada práctica.

## Sintaxis y variables

- [ ] Explico la diferencia entre `let`, `const` y `var`.
- [ ] Declaro todo con `const` y solo uso `let` cuando reasigno.
- [ ] Identifico los tipos: `number`, `string`, `boolean`, `null`, `undefined`, `object`, `symbol`.
- [ ] Uso `typeof` para comprobar tipos en consola.
- [ ] Aplico operadores aritméticos, de comparación estricta (`===`/`!==`) y lógicos (`&&`, `||`, `!`).

## Funciones

- [ ] Escribo funciones declaradas y funciones flecha.
- [ ] Devuelvo valores y capturo el resultado en variables.
- [ ] Comprendo parámetros, argumentos y valores por defecto.
- [ ] Evito efectos colaterales: prefiero funciones que reciben datos y devuelven un resultado.

## Arrays y objetos

- [ ] Creo y recorro arrays con `for...of`.
- [ ] Transformo con `map` y devuelvo un nuevo array.
- [ ] Filtro con `filter` sin mutar el original.
- [ ] Acumulo con `reduce` (suma, valor máximo, conteo).
- [ ] Leo y modifico propiedades de objetos, incluidas las anidadas.

## DOM y eventos

- [ ] Selecciono elementos con `document.querySelector`.
- [ ] Selecciono grupos con `document.querySelectorAll` y los convierto con `Array.from` o spread.
- [ ] Escucho clics con `addEventListener('click', ...)`.
- [ ] Leo el valor de `input` con `.value` y lo limpio después de usarlo.
- [ ] Creo elementos con `document.createElement` y los agrego con `append`.

## Práctica final

- [ ] Construyo una lista dinámica con formulario (plantilla del nivel) sin mirar el código.
- [ ] Añado validación de entrada vacía y duplicados.
- [ ] Añado un contador de elementos totales usando `length` y `reduce`.
- [ ] Explico en voz alta cada línea de la plantilla `script.js` del nivel básico.
