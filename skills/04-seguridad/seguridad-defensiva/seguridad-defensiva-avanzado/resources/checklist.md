# Checklist — Seguridad defensiva nivel avanzado

## Diagnóstico
- [ ] Matriz NIST CSF 2.0 completada con puntuación
- [ ] Huecos priorizados con plan de 90 días

## Protect
- [ ] Hardening documentado por servicio
- [ ] Segmentación mínima (público vs interno)
- [ ] Parches con criterio (críticos en 7 días)

## Detect
- [ ] Logs centralizados de todos los servidores
- [ ] Reglas accionables (cada alerta = acción definida)
- [ ] fail2ban u equivalente para servicios públicos
- [ ] FIM sobre archivos críticos
- [ ] Controles mapeados a D3FEND

## Respond
- [ ] Playbook de incidente escrito
- [ ] Simulación ejecutada y alertas verificadas
- [ ] Canal de comunicación definido

## Recover
- [ ] RTO/RPO definidos
- [ ] Restauración probada recientemente

## Govern
- [ ] Políticas con dueño y revisión trimestral
- [ ] Retención de logs definida
