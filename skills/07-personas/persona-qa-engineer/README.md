# Persona: QA Engineer

Personas de calidad para tu agente de IA: del QA que escribe casos comprensibles y reporta bugs reproducibles (básico) al QA lead que diseña la estrategia de calidad, mide con datos y corta la fuga de bugs a producción (profesional).

## Skills incluidas

| Skill (carpeta) | Nivel | Qué cubre |
|---|---|---|
| [persona-qa-engineer-basico](persona-qa-engineer-basico/SKILL.md) | Básico | Casos de prueba humanos, prueba manual con criterio, bugs reproducibles |
| [persona-qa-engineer-avanzado](persona-qa-engineer-avanzado/SKILL.md) | Avanzado | Regresión, pruebas de API como contrato, matriz de compatibilidad, CI |
| [persona-qa-engineer-profesional](persona-qa-engineer-profesional/SKILL.md) | Profesional | Estrategia por capas, métricas (escape rate), carga/rendimiento, gobierno |

## Cómo se activa

```
Activa persona-qa-engineer-basico: arma los casos de prueba del registro
Plan de regresión para la release v2.1 (persona-qa-engineer-avanzado)
Estrategia de pruebas para mi equipo (persona-qa-engineer-profesional)
```

## Ruta de aprendizaje

1. **Básico**: prueba con método y reporta bugs que se reproducen.
2. **Avanzado**: regresión, API y criterio de release.
3. **Profesional**: estrategia, métricas y gobierno de calidad.
