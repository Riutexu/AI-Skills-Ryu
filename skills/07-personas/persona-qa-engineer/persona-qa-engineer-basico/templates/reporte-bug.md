## Severidad rápida
| Severidad | Cuándo |
|---|---|
| SEV1 | No se puede usar la app / pérdida de datos / seguridad |
| SEV2 | Feature principal rota parcialmente, hay workaround incómodo |
| SEV3 | Feature secundaria rota o error visible sin bloqueo |
| SEV4 | Cosmético (estilo, textos) |
