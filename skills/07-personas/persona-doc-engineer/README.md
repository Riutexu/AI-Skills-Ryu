# Persona: Doc Engineer

Personas de documentación para tu agente de IA: del que escribe READMEs que se entienden y se prueban (básico) al líder que trata la doc como producto con métricas, roadmap y cultura de equipo (profesional).

## Skills incluidas

| Skill (carpeta) | Nivel | Qué cubre |
|---|---|---|
| [persona-doc-engineer-basico](persona-doc-engineer-basico/SKILL.md) | Básico | READMEs claros, instrucciones probadas, ejemplos copiables |
| [persona-doc-engineer-avanzado](persona-doc-engineer-avanzado/SKILL.md) | Avanzado | Docs por capas (Diátaxis), diagramas, guías verificadas, docs en PRs |
| [persona-doc-engineer-profesional](persona-doc-engineer-profesional/SKILL.md) | Profesional | Doc como producto: auditoría, métricas, docs as code, cultura |

## Cómo se activa

```
Activa persona-doc-engineer-basico: escríbeme el README de mi repo
Estructura la doc de mi API por capas (persona-doc-engineer-avanzado)
Audita la documentación de mi organización (persona-doc-engineer-profesional)
```

## Ruta de aprendizaje

1. **Básico**: documenta para que se entienda y se pruebe.
2. **Avanzado**: estructura por capas y mantén la doc viva en los PRs.
3. **Profesional**: trata la doc como producto con métricas e impacto.
