# Checklist — Seguridad defensiva nivel profesional

## Hunting
- [ ] Hipótesis definidas por campaña/riesgo
- [ ] Consultas/reglas Sigma ejecutadas sobre histórico
- [ ] Resultado documentado (confirmado/descartado/pendiente)

## Inteligencia (CTI)
- [ ] Feeds con contexto, no ruido
- [ ] IoCs correlacionados con telemetría propia
- [ ] Priorización según negocio

## Detección
- [ ] Reglas con dueño, caso de uso y revisión
- [ ] Falsos positivos medidos y reducidos
- [ ] Cobertura de técnicas ATT&CK revisada

## Respuesta
- [ ] Playbooks por tipo de incidente probados
- [ ] SOAR/semi-automatización de lo repetitivo
- [ ] Contención/erradicación/recuperación con registro

## Métricas
- [ ] MTTR medido
- [ ] Alertas revisadas con SLA cumplido
- [ ] Ejercicio conjunto con red team realizado
- [ ] Informe mensual de mejora

## Post-incidente
- [ ] Post-mortem con acciones asignadas
- [ ] Cambios en reglas/playbooks aplicados
